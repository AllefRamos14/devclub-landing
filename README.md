# ✨ Sobre

Este projeto foi desenvolvido para o desafio técnico **Full Stack do DevClub**, cujo objetivo era criar uma landing page institucional moderna, impactante e visualmente diferenciada.

A proposta foi construir uma interface inspirada em produtos SaaS modernos, priorizando:

- excelente experiência do usuário;
- design premium;
- animações suaves;
- microinterações;
- código limpo;
- organização escalável;
- alta performance.

Todo o projeto foi desenvolvido utilizando o ecossistema React moderno com TypeScript.

# 🧠 Decisões Técnicas

### Styled Components

Foi escolhido para manter os estilos isolados por componente, facilitar manutenção, reutilização e gerenciamento de temas.

---

### Framer Motion

Responsável pelas animações de entrada, efeitos de hover, transições e microinterações sem comprometer a performance.

---

### Vite

Escolhido pela velocidade durante o desenvolvimento e excelente otimização do build final.

---

### TypeScript

Garantiu maior segurança no desenvolvimento, melhor manutenção e escalabilidade do projeto.

---

### Organização por Seções

Cada parte da Landing possui sua própria estrutura, facilitando evolução futura do projeto.

# 🚀 Como executar

### Clone o projeto

```bash
git clone https://github.com/AllefRamos14/devclub-landing.git
```

Entre na pasta

```bash
cd devclub-landing
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm run dev
```

Gerar Build

```bash
npm run build
```
